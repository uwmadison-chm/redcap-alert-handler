# REDCap Alert Handler: (`rah`) An Event Queue for REDCap Alerts

This is a python utility that processes email generated by REDCap in close-to-realtime, using an Office 365 mailbox, accessed through the Microsoft Graph API, as a durable message queue. It's written primarily by Nate Vack <njvack@wisc.edu> with help from various AI tools.

More details on the project and design goals are in DESIGN_BRIEF.md.

A guide to implementation (libraries, configuration, steps) is in IMPLEMENTATION_PLAN.md.
